# GenAI Full Stack Project

This repository contains the backend application under the `Backend/` folder.

## Backend
- `Backend/server.js` - entry point
- `Backend/src/app.js` - Express app setup
- `Backend/src/controllers` - route handlers and controllers
- `Backend/src/models` - Mongoose schemas/models
- `Backend/src/routes` - Express route definitions

## Setup
1. Copy `.env` into `Backend/.env`.
2. Run `npm install` in the `Backend` folder.
3. Start the backend with `npm run dev`.
